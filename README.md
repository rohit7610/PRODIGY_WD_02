# PRODIGY_WD_02

## Stopwatch Web Application

A responsive and interactive stopwatch web application developed as part of the Prodigy Infotech Web Development Internship.

### Features

- Start stopwatch
- Pause stopwatch
- Resume stopwatch
- Reset stopwatch
- Record lap times
- Display recorded lap times
- Responsive design

### Technologies Used

- HTML5
- CSS3
- JavaScript
